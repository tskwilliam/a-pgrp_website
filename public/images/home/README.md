# Home page hero images

Place your hero slideshow images in this folder.

Supported formats: .jpg, .jpeg, .png, .webp

Then update the HERO_IMAGES array in src/pages/Home.tsx:

  const HERO_IMAGES = [
    '/images/home/hero-1.jpg',
    '/images/home/hero-2.jpg',
    '/images/home/hero-3.jpg',
  ]

Images are displayed full-screen (cover fit). Landscape orientation works best.
Recommended minimum size: 1920 × 1080 px.
